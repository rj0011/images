# Images – Gallery & Player

Premium offline photo, video & music gallery (PWA). Designed by Manish Shukla.

- Photos: timeline, pinch-zoom viewer, slideshow, EXIF/GPS info, editor (filters, adjust, crop, rotate)
- Videos: gestures (brightness/volume/seek), double-tap ±10s, hold for 2×, speed, subtitles, PiP, A-B loop, resume, frame capture
- Music: songs/albums/artists/playlists, equalizer, visualizer, sleep timer, lock-screen controls
- Albums, search, favourites, recycle bin (30 days), Vault with pattern + fingerprint lock
- Files are stored privately on the phone (OPFS/IndexedDB). Nothing is uploaded.
